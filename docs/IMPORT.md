# Подписки в AlterTube (как в NewPipe, за 5 минут)

AlterTube не просит Google-вход: подписки живут только на телефоне, как в NewPipe.
Вкладка **Подписки** → кнопка **+** → четыре пути.

## 1. Выбрать файл (как в NewPipe)

1. Нажми **+ → Выбрать файл**.
2. Укажи файл — разбирать ничего не надо, экстрактор сам поймёт формат:
   - **Takeout-архив `.zip` целиком** (качать тут: takeout.google.com → только «подписки»);
   - `subscriptions.json` или `subscriptions.csv` из этого архива;
   - бэкап NewPipe / PipePipe / наш (`.json`).
3. Увидишь «Импортировано каналов: N». Дубли пропускаются.

## 2. Вставить текст / один канал

**+ → Вставить текст**: ссылка, `@handle`, UC-id, название канала — или целиком
содержимое файла (NewPipe / Takeout / CSV / список ссылок, по одной на строку).

Отписаться: долгое нажатие на аватар канала → «Да».

## 3. Экспорт (бэкап)

**+ → Экспорт подписок** — сохранит `altertube_subs.json` в выбранную папку.
Файл понимают NewPipe, PipePipe и мы (через «Выбрать файл»).

## 4. Вход через cookie (18+ и приватное)

Гугл-формы входа нет (как и в NewPipe), но экстрактор умеет работать с cookie:

1. На компьютере в браузере поставь расширение «Get cookies.txt» или «EditThisCookie».
2. Открой youtube.com, выгрузи cookie строкой, скопируй.
3. **+ → Вход через cookie** → вставь → Сохранить.

После этого открываются возрастные и приватные видео твоего аккаунта.
Дата установки видна в том же пункте меню.

## Что стоит знать

- Лента **Подписок** подтягивается не мгновенно: приложение опрашивает каналы
  параллельно (по 3 свежих видео), при 429 подожди минуту и потяни вниз.
- Каналы-«топики» (автосгенерированные YouTube) иногда отдают пустую ленту —
  так же ведёт себя и NewPipe.
- Повторный импорт тех же каналов дубли не создаёт.
