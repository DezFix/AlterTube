# Перенос подписок в AlterTube (за 5 минут)

AlterTube не просит Google-вход: подписки живут только на телефоне, как в NewPipe.
Есть два пути: добавить каналы по одному или переехать всё разом.

## Быстрый путь: по одному каналу

1. Открой вкладку **Подписки** → кнопка **+** сверху.
2. Вставь что угодно из этого:
   - ссылку (`https://www.youtube.com/@канал` или `.../channel/UC...`),
   - `@handle`, UC-id (`UC...`) или просто название канала.
3. Нажми **Добавить**. Готово.

Отписаться: долгое нажатие на аватар канала → «Да».

## Переезд разом: вставь файл целиком

Там же в **+ Добавить** можно вставить **весь текст файла** — формат определится сам,
после вставки покажет «Импортировано (формат): N». Что подойдёт:

### 1. NewPipe-экспорт (самый точный)

1. NewPipe → вкладка **Подписки** → меню **⋮ → Экспорт в → файл** (получишь JSON).
2. Открой файл любым текстовым редактором, скопируй всё.
3. Вставь в AlterTube. Каналы не из YouTube (`service_id != 0`) пропускаются.

### 2. Google Takeout

1. Открой https://takeout.google.com/takeout/custom/youtube → оставь только
   **«подписки»** → создай экспорт и дождись письма.
2. Из zip-архива достань `YouTube и YouTube Music/subscriptions/subscriptions.json`.
3. Скопируй содержимое целиком и вставь в AlterTube.

Под рукой только компьютер? Можно заранее конвертнуть файл скриптом:

```bash
python tools/parse_takeout.py subs.json app_subs.json [--to altertube|newpipe]
```

С `--to newpipe` получится файл, который съедят и NewPipe, и AlterTube.

### 3. CSV из Takeout или простой список

- CSV (`Channel Id,Channel Url,Channel Title`, названия с запятыми в кавычках — можно)
  вставляется как есть.
- Или просто список: по одной ссылке / UC-id / `@handle` на строку.

## Что стоит знать

- После импорта лента **Подписок** подтягивается не мгновенно: приложение вежливо
  опрашивает каналы параллельно (по 3 свежих видео с канала), при 429 подожди минуту.
- Каналы-«топики» (автосгенерированные YouTube) иногда отдают пустую ленту —
  так же ведёт себя и NewPipe, это не баг импорта.
- Повторный импорт тех же каналов дубли не создаёт.
